This repository holds an idea and no code: a REST API that lets a hot wallet sign transactions on behalf of a set of users, so they don't need their own wallets. It was never built, and it's archived.

> [!WARNING]
> If you build something like this, a shared hot wallet is a custody risk. Whoever controls the server or its key controls every user's funds, one bug or leaked key can lose them all, and holding funds for others can bring legal duties.

## If you are looking for working code

[CoinClub_Framework](https://github.com/CoinClubQuincy/CoinClub_Framework) is a Python library with wallet support across several chains.
